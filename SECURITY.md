# Security Policy

## Supported Versions

This is a small academic project without versioned releases. The current `main` branch is the only supported version.

| Branch | Supported |
|--------|-----------|
| `main` | Yes |

## Reporting a Vulnerability

This is a desktop application with no network calls, no user data storage, and no external API access. Security risk is minimal.

If you identify a security concern, please report it by:

- Opening a GitHub issue in this repository, or
- Sending an email to opeblow2021@gmail.com

We will review and address reports as promptly as possible.
